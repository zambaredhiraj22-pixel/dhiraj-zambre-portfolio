# Dhiraj Zambre — Portfolio Website

This is a responsive static portfolio website. It is ready to preview locally and deploy to a static host.

## Preview locally

Open `index.html` in a web browser.

## Personalize before sharing

- Replace GitHub, LinkedIn and email placeholders in `index.html`.
- Add your real resume PDF as `resume.pdf` in this folder.
- Add verified GitHub/live demo URLs for your projects.
- Verify all internship dates, skills and experience descriptions.

## Get a temporary public link (Netlify Drop)

1. Open https://app.netlify.com/drop in your browser and sign in if prompted.
2. Unzip this folder on your computer.
3. Drag the `dhiraj-portfolio` folder (containing `index.html`) onto the drop area.
4. Netlify will publish it and provide a public `netlify.app` URL.

## Alternative: Vercel

Vercel normally deploys through a connected Git repository or its CLI. See https://vercel.com/docs/frameworks/frontend/vite . This package is static HTML, so Netlify Drop is the simpler option without needing a build step.
